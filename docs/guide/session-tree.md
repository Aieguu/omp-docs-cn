# 会话树

[Sessions](./sessions.md) 涵盖了日常使用的参数。本页深入一层：树的实际结构、每个导航命令如何影响叶子指针，以及导出、分享和恢复如何从中读取。

## 每个条目都有一个父节点

会话文件是仅追加的 JSONL。每个非头部条目都带有 `id` 和 `parentId`——是这些指针（而非行顺序）定义了对话结构。运行时为每个会话额外跟踪一个状态：`leafId`，即下一个追加操作将挂载到的条目。追加操作始终在当前叶子节点下创建子节点。分支操作不会重写旧条目；它只是在下一次追加之前移动叶子指针。

这意味着一个文件可以包含多个线程。"活动路径"是从叶子节点沿 `parentId` 回溯到根节点所经过的路径。其他内容仍然存在于文件中，并且对 `/tree` 可见。

```
root
├─ user: "Start task"
│  └─ assistant: "Plan"
│     ├─ • user: "Try approach A"   ← leaf
│     │  └─ • assistant: "A result"
│     └─ user: "Try approach B"
│        └─ assistant: "B result"
```

## `/tree` —— 原地移动叶子节点

`/tree` 打开文件内导航器。它不会创建新文件或修改历史记录；它只是重新指向 `leafId`。

选择器内的操作键：

- ↑/↓ 移动；←/→ 翻页。
- 输入文字可模糊搜索渲染后的文本、标签、角色和工具片段。
- Shift+L 设置或清除高亮条目上的标签。标签作为独立条目持久化，并成为书签。
- Ctrl+O 循环切换过滤器；Alt+D/T/U/L/A 跳转到默认、无工具、仅用户、仅带标签或全部。

按 Enter 时的行为取决于条目类型：

- **用户或自定义消息** —— 叶子节点移动到该条目的_父节点_，消息文本被复制到编辑器中以便编辑和重新提交。选择第一个用户提示词会将叶子节点重置到根节点。
- **其他类型**（助手、工具结果、摘要、记录） —— 叶子节点移动到所选条目。编辑器不会预填充。
- **当前叶子节点** —— 无操作；选择器关闭并显示"Already at this point"。

如果 `branchSummary.enabled` 开启，移动前会出现摘要提示；生成的 `branch_summary` 条目会被追加在新位置，而不是被丢弃的尾部。

## `/branch` vs `/fork`

两者都会创建新的叶子节点。区别在于是否会创建新文件。

`/branch` 打开用户消息选择器，从所选提示词开始在_同一文件中_创建新线程。原始分支仍可通过 `/tree` 访问。当你希望一个文件成为某次探索的规范记录时使用。

`/fork` 将整个当前会话复制到一个全新的 JSONL 中，用新 ID 重写头部，设置 `parentSession` 为旧 ID，并将活动会话切换到副本。原始文件保持不变。当替代方案可能被放弃且你不希望它干扰父会话的 `/tree` 视图时使用。制品目录会随文件一起复制。`/fork` 在轮次流式传输期间被阻止，在 `--no-session` 下被禁用。

新头部中的 `parentSession` 字段是唯一的血统标记——它允许工具回溯到源会话，但分叉在其他方面是独立的。

## 恢复选择叶子节点

恢复操作都定位到文件上次写入时的叶子节点：

- `omp -c`（`--continue`）优先使用每个终端的面包屑记录，然后回退到当前目录中按修改时间排序的最新文件。
- `omp -r <prefix>` 在当前项目中匹配 ID，然后全局匹配。跨项目匹配会提示你将其分叉到当前目录，而不是静默切换目录。
- `omp --fork <id|path>` 始终生成一个带有 `parentSession` 的新文件，跳过提示。
- `--resume <path.jsonl>` 直接打开文件。

会话内，`/resume` 仅列出当前目录中的会话，并使用 `switchSession` 就地交换状态——模型、思考级别、MCP 选择和 todo 都会从新文件的活动路径重建。

## 导出、转储、分享

三者都渲染**活动的根→叶路径**，而非整个文件。你通过 `/tree` 丢弃的分支不会出现在 HTML 或 `/dump` 中。

- `/export [path]` 和 `omp --export <file>` 写入自包含的 HTML 渲染。
- `/dump` 将纯文本记录复制到剪贴板——系统提示词、工具、消息、结果。
- `/share` 导出为临时 HTML 并运行 `~/.omp/agent/share.{ts,js,mjs}`（如果存在）；否则通过 `gh` 上传秘密 gist。

要分享其他分支，先 `/tree` 到该叶子节点，然后导出。要分享文件中的_所有内容_而不考虑叶子位置，直接发送 JSONL 文件——接收者可以 `omp --resume ./file.jsonl` 并使用 `/tree` 浏览。
