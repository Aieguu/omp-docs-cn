# 会话树

只要你在较早的某个点重新回看这段对话并从那里换个方向继续，这段对话就变成了一棵树。omp 会保留你已经走过的路径，并在它旁边添加新的路径，因此做各种尝试并不需要删除有用的成果。

最小的操作是：

```
/tree
```

使用导航器选择你想从哪里继续。

## 读懂会话树

`/tree` 会打开一份覆盖整个会话的地图。各行之间用树状连线连接，兄弟行是从同一点延伸出的不同延续。

*   在**当前活动路径**上的每一行，都会用强调圆点标记。
*   高亮的行是你在考虑的点；在你按 Enter 之前它并不会成为活动点。
*   用户与助手的文本用来标识各轮对话。工具活动与会话事件也可能出现，具体取决于过滤器。
*   标签出现在它所在行的前面，作用相当于一个持久的书签。
*   非常深的缩进会用省略号压缩，以保证消息文本仍然可读。

默认过滤器偏向对话类条目。如果某个会话看起来异常稀疏，按 Alt+A 显示全部内容。输入消息、标签、角色或工具片段中的任意一部分文字，即可缩小地图范围。

```
• You: Investigate the failing build
  • Assistant: The failure starts in authentication
    ├─ • You: Patch the token refresh path
    │    • Assistant: Tests now pass
    └─ You: First check whether the cache is stale
         Assistant: The cache is healthy
```

在这里，圆点标记的是处于活动状态的 token 刷新路径。缓存检查仍然作为另一条分支存在。

## 从更早的轮次继续

要想修改一条之前的请求而不丢失它原来的结果：

1.   运行 `/tree`。
2.   高亮那条较早的**用户消息**。
3.   按 Enter。
4.   omp 会移动到该消息之前紧邻的位置，并把这条消息——包括它的图片附件——恢复成一份可编辑的草稿。
5.   修改草稿并提交。

提交后会在旧的延续旁边创建一条新的延续。原来的消息、它的回答以及其后的所有内容，都仍然可以在 `/tree` 中访问到。

如果改选一条助手回复，则会直接落在该回复之后，并让编辑器保持为空。你的下一条提示词会从那里继续。选择当前端点则只是以 “Already at this point” 的状态关闭导航器。

过去提出的交互式问题同样可以恢复：选择一条较早的 `ask` 回答会重新打开提问界面，新的回答会成为旧回答的兄弟条目。

### 保留你离开的路径上有用的上下文

当 `branchSummary.enabled` 开启时，按 Enter 会提供三个选项：

*   **No summary（不生成摘要）** —— 仅用所选路径上的上下文继续。
*   **Summarize（生成摘要）** —— 把你正要离开的路径的一份自动生成的总结带到新的路径中。
*   **Summarize with custom prompt（用自定义提示词生成摘要）** —— 告诉 omp 这份总结应当保留什么。

按 Shift+Enter 即可在不打开该选项的情况下直接生成摘要并切换。这份总结归属于新路径；它不会替换或删除被放弃的路径。在摘要运行期间按 Esc 可取消并返回会话树。

## `/tree`、`/branch` 还是 `/fork`？

这些控件保留的历史信息量各不相同：

| 命令 | 结果 | 适用场景 |
| --- | --- | --- |
| `/tree` | 在当前会话文件内移动。你的下一次提交会在文件内添加一条替代路径，而所有已有路径仍保留在同一棵树中。 | 探索各种替代方案，同时保留一份可整体导航的记录。 |
| `/branch` | 遵循 **Double-Escape Action**。使用默认的 **Tree** 设置时，它打开的是与 `/tree` 相同的文件内导航器。将该动作设置为 **Branch**，即可选择一条较早的用户消息，并创建一个只包含它之前路径的独立会话；所选消息会以草稿形式返回。 | 决定 branch 命令的含义是文件内导航，还是从较早的决策点开启一个干净的新会话。 |
| `/fork` | 立即把当前会话——包括它当前的树与制品——克隆到一个新会话中，然后切换到该克隆。它不会询问更早的轮次。 | 在进行大范围或有风险的实验之前，先建立一个完整的检查点。 |

一个实用的经验法则：想在地图中比较不同路径时用 `/tree`。要让 `/branch` 创建独立的先导会话，请打开 `/settings`，进入 **Interaction → Input**，并把 **Double-Escape Action** 设置为 **Branch**。当你想要一份当下所有内容的完整独立副本时，用 `/fork`。

这项设置也决定了在空编辑器中按两次 Esc 的效果：打开树、打开分支选择器，或者什么都不做。

`/fork` 需要一个已经持久化的会话，并且不能在回复流式传输期间运行。对于以 `--no-session` 启动的会话，它不可用。

## 导航控制

| 按键 | 操作 |
| --- | --- |
| ↑ / ↓ | 在可见行之间移动一行；到两端时回绕 |
| Alt+↑ / Alt+↓ | 跳到上一条或下一条用户/助手轮次 |
| Page Up / Page Down 或 ← / → | 每次移动一页 |
| Home / End | 跳到第一条或最后一条可见行 |
| 输入文字 | 搜索可见的树；Backspace 删除搜索字符 |
| Enter | 切换到高亮的点 |
| Shift+Enter | 先摘要将要离开的路径，再切换 |
| Shift+L | 在搜索为空时添加、编辑或清除标签 |
| Ctrl+O | 向前循环切换过滤器 |
| Ctrl+Shift+O | 向后循环切换过滤器 |
| Alt+D/T/U/L/A | 显示默认、无工具、仅用户、仅带标签或全部条目 |
| Esc 或 Ctrl+C | 先清除活动的搜索；否则关闭导航器 |

如果你预期会回到某个特定的检查点，可以在一次较长的实验之前先使用标签。之后，Alt+L 就只显示带标签的条目。

## 持久化与压缩

已完成的轮次与所有分支都会存储在会话日志中。常规的树导航不会重写或抹除更早的路径。

所选的点会立即成为活动端点。你的下一次提交、一条分支摘要或常规的会话退出记录都会在该路径上写入一条条目，因此恢复时会跟随它。如果只是做了一次导航移动、还未来得及写入任何内容时 omp 就被终止，恢复时可能会回到日志中已经存在的最后一个端点；重新打开 `/tree` 并再次选择目标路径即可。

[压缩](./compaction.md) 改变的是在某条路径上发送给模型的上下文；它不会把树压平，也不会删除产生摘要的那些轮次。经过压缩点的路径会使用那份被压缩后的上下文。导航到压缩点之前的某个点，可以让你从更早的上下文继续，其他分支仍然可见。

分支摘要与压缩摘要解决的是不同的问题：

*   一条**分支摘要**在有意切换到另一条路径时携带有用的信息。
*   一份**压缩摘要**会缩短活动路径，使对话能够在模型的上下文窗口内继续。

## 从错误的选择中恢复

如果你移到了错误的点，不要重建这段对话：

1.   再次运行 `/tree`。
2.   搜索有辨识度的文字，或按 Alt+L 找一个书签。
3.   沿着树状连线走到原始路径的端点。
4.   按 Enter 选择该端点。

原始路径会重新变为活动路径。如果你已经在错误的路径上提交过内容，这份新工作同样会作为兄弟分支保留下来；返回不会删除任何一侧。

如果希望在实验之前建立更强的边界，先使用 `/fork`。如果实验进展不顺利，你仍然可以通过 `/resume` 独立恢复原始会话。
